# Upgrading FLEX v3 → v4

Every breaking change in FLEX v4.0.0 and what a FLEX child theme must do about it.

## Removed

- **`__GET_STARTED_HERE/` starter kit removed.** It was an obsolete `flexlayout-child` starter (webpack 4 config, PostCSS/Babel/ESLint configs, `.githooks`, a sample `.env`). Start a new child theme from the reference child build config in this document instead.
